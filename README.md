# Набор навыков для Claude Code

47 готовых навыков: дизайн интерфейсов, безопасность, скорость сайтов, бэкенд,
видео, работа с текстом. Что это за навыки и зачем каждый — в [ЧТО-ВНУТРИ.md](ЧТО-ВНУТРИ.md).

## Установка одной командой

```bash
git clone https://github.com/Sanych64/claude-skills.git /tmp/claude-skills && bash /tmp/claude-skills/install.sh
```

После этого перезапусти Claude Code — навыки появятся сами.

Если какие-то навыки у тебя уже стоят, скрипт их не тронет и скажет об этом.
Чтобы перезаписать своими — добавь `--force` в конце команды.

## Или через сам Claude Code

Открой Claude Code и вставь это сообщением:

> Склонируй https://github.com/Sanych64/claude-skills.git во временную папку,
> запусти оттуда install.sh, покажи список того, что поставилось, и объясни
> коротко по-русски, какие навыки для чего. Потом удали временную папку.

## Что такое навык

Это заранее написанная инструкция для Claude по конкретному делу. Запускать
вручную ничего не нужно: пишешь обычную задачу — «сделай лендинг», «проверь
код на уязвимости», «ускорь сайт» — и Claude сам берёт подходящий навык.

## Откуда это

Навыки собраны из открытых репозиториев: Anthropic, Vercel, Supabase, Remotion,
Emil Kowalski, Andrej Karpathy, OWASP и других авторов. Это чужая работа,
выложенная в открытый доступ.
